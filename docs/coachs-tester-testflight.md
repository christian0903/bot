# Tester l'application avant les membres — TestFlight

> À transmettre aux coachs. Ce document explique comment installer la version
> de test sur son iPhone, ce qu'il faut regarder, et comment signaler ce qui
> ne va pas.

L'application est en vente sur l'App Store. Avant qu'une nouvelle version
n'arrive chez les membres, vous la recevez en avance par **TestFlight**, une
application d'Apple faite pour cela.

Vous recevrez un **lien** — pas une invitation nominative. Il n'y a donc rien à
nous communiquer pour y accéder : ni identifiant, ni adresse.

---

## ⚠️ À lire avant tout : JAG et TestFlight ne sont pas la même chose

Vous connaissez déjà **JAG** (`jag.backontrackstudio.be`), où vous avez pris
l'habitude d'essayer les nouveautés. TestFlight est autre chose, et **la
différence porte sur les données**.

| | **JAG** — `jag.backontrackstudio.be` | **TestFlight** — l'app au point orange |
|---|---|---|
| Les données | **Fausses.** Membres et cours inventés | **Réelles.** Vos membres, vos cours |
| Les paiements | Fictifs | **Réels — la carte est débitée** |
| Ce qu'on peut y faire | **Tout.** Réserver, annuler, supprimer, recommencer | Ce qu'on ferait un jour ordinaire |
| Une erreur | Sans conséquence — on efface et on refait | **Touche un vrai membre** |
| À quoi ça sert | Découvrir, s'entraîner, essayer sans risque | Vérifier qu'une version tient avant les membres |

**Sur JAG, allez-y franchement.** C'est fait pour cela : inscrivez dix
personnes à un cours, annulez tout, supprimez un compte pour voir. Rien de ce
que vous y faites n'existe en dehors. Si vous voulez comprendre un écran ou
vous exercer à un geste, c'est là qu'il faut le faire.

**Sur TestFlight, agissez comme en vrai.** Ce n'est pas une répétition : la
réservation que vous créez apparaît dans l'agenda d'un vrai membre, le pointage
que vous faites entre dans ses statistiques, un compte supprimé l'est
réellement. C'est précisément ce qui donne sa valeur au test — on éprouve
l'application dans les conditions du studio — mais cela demande la même
attention qu'un jour de travail ordinaire.

> **Comment savoir où vous êtes ?** Sur JAG, un **bandeau orange « BASE DE
> TEST »** s'affiche en haut de l'écran. Sur TestFlight, **aucun bandeau** :
> vous êtes sur les données du studio. Le point orange à côté de l'icône, lui,
> ne dit pas quelles données vous manipulez — il signale seulement que
> l'application vient de TestFlight et non de l'App Store.
>
> Autrement dit : **bandeau = on peut tout casser ; pas de bandeau = c'est
> pour de vrai.**

**En cas de doute, un réflexe simple** : si vous voulez juste *voir comment ça
marche*, faites-le sur JAG. TestFlight sert à répondre à une autre question —
« est-ce que cette nouvelle version fonctionne correctement sur mes vraies
données ? »

---

## 1. Installer TestFlight

Sur l'App Store de votre iPhone, cherchez **TestFlight** et installez-la. Elle
est gratuite, éditée par Apple. C'est elle qui vous remettra nos versions de
test.

## 2. Rejoindre le test

Ouvrez le lien que nous vous avons envoyé **depuis votre iPhone**. Il bascule
tout seul vers TestFlight, qui vous propose d'**installer** Back on Track
Studio.

> **Ouvrez-le sur le téléphone, pas sur l'ordinateur.** Sur un ordinateur, le
> lien affiche une page qui ne mène nulle part.

## 3. Reconnaître la version de test

Une fois installée, l'application porte un **point orange** à côté de son nom
sur l'écran d'accueil. C'est ce qui la distingue de celle de l'App Store.

**Les deux peuvent cohabiter** sur le même téléphone. Si vous aviez déjà
installé l'application, gardez-la : vous aurez deux icônes, et le point orange
vous dira laquelle est la version de test.

Connectez-vous avec **votre compte Back on Track habituel** — le même identifiant
et le même mot de passe que d'ordinaire.

---

## Ce qu'il faut savoir avant de commencer

**Vous travaillez sur les vraies données** — voir l'encadré en tête de ce
document. Pour manipuler sans conséquence, c'est **JAG** qu'il faut ouvrir.

**Les paiements aussi sont réels.** Le studio encaisse pour de vrai depuis le
30 août : un pack acheté depuis TestFlight débite la carte, comme depuis
l'application ordinaire. **N'achetez rien « pour voir »** — si vous devez
éprouver un achat, faites-le sur JAG, où les paiements sont fictifs.

**Une version de test expire au bout de 90 jours.** L'application cesse alors
de s'ouvrir. Ce n'est pas une panne : il suffit d'installer la version suivante
depuis TestFlight.

---

## Ce que nous vous demandons de regarder

Vous recevez à chaque version une liste de points précis, affichée dans
TestFlight sous le nom **« Éléments à tester »**. Lisez-la : elle dit ce qui a
changé depuis la dernière fois.

Au-delà de cette liste, ce qui nous intéresse le plus :

- **ce qui vous surprend** — un écran qui ne montre pas ce que vous attendiez,
  un nombre qui semble faux, un cours qui n'apparaît pas ;
- **ce qui vous ralentit** — un geste qui demande trop de manipulations, un
  bouton qu'on ne trouve pas ;
- **ce qui vous fait hésiter** — si vous ne savez pas quoi faire devant un
  écran, c'est un défaut de l'application, pas le vôtre.

---

## Signaler un problème

**Le plus simple : faites une capture d'écran** (les deux boutons latéraux de
l'iPhone en même temps). TestFlight vous propose alors **« Partager le retour
avec le développeur »**. Ce chemin nous transmet la capture *et* les
informations techniques qui vont avec — quel appareil, quelle version, ce qui
se passait à ce moment-là. C'est ce qui nous permet de comprendre sans avoir à
vous rappeler.

**Sinon, dites-le simplement à Christian**, par le canal habituel.

Dans les deux cas, précisez **ce que vous étiez en train de faire** au moment
où le problème est apparu. « Ça ne marche pas » est difficile à corriger ;
« j'ai touché le cours de 18 h et la liste est restée vide » se répare.

---

## Si l'application se bloque

Cela peut arriver — ce sont des versions en cours de mise au point. Fermez
l'application et rouvrez-la ; si le problème persiste, prévenez-nous
directement plutôt que d'insister.

En attendant une correction, **l'application installée depuis le site**
(`app.backontrackstudio.be`) reste disponible et fonctionne normalement : c'est
la même application, dans sa version stable.
